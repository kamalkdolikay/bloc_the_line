Tiles are 16x16 pixels

Wizards are 32x32 pixels

Movement is 2 frame
- Tags used: "Move"

Placing and idle is 3 frame
- Placing Tag: "Place"
- Idle Tag: "Idle"

Currently the textures are stored as .ase, this format is storing:
 - multiple frames (animation)
 - multiple layers (unused)
 - timing (frame duration)
 - palettes
 - transparency
 - tags (for idle/move/attack)
 - allows us to reopen and edit the textures
 * later we export to png/jpg *
